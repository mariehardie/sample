# Знакомство с разметкой md
## [Документация Git](https://git-scm.com/)
### Перечень команд git:


- **git init** - _создание репозитория .git. Это служебная директория, которая содержит базу данных и некоторые настройки для git. Она всегда в корне нашего проекта._  


> На одном компьютере git позволяет зарегистрировать несколько пользователей с их различными проектами. Также git позволяет ставить настройки:
> 1. общесистемные:  `--system`
> 2. на уровне конркетного пользователя:  `--global`
> 3. локальные:  `--local`  
>
>***Имя и почту пользователя лучше делать глобальными***  

- **git config** - _локальный уровень конфигурации(применяется к текущему репозиторию)_

- **git config --list** - _значения параметров конфигурации(собирает настройки из всех трёх уровней)_

- **git config --list --global** - _глобальные значения параметров конфигурации_
    - **cat ~/.gitconfig** - _посмотреть сам файл в домашней директории_    

---    

- **git config --unset user.name**- _удаление одного локального параметра(имя пользователя)_

- **git config --remove-section user**- _удаление всей секции user, включая все поднастройки_

- **git config --global core.editor**- _установка текстового редактора для git по умолчанию для всех репозиториев_  

---    

- **git config --global alias.c config** - _создание алиаса(псевдонима для команды)_

- **git config --global alias.c 'config --global'** - _создание алиаса(команда подлиннее)_

- **git config alias.sayhi '!echo "hello"; echo "from git"'** - _создание алиаса на несколько команд сразу(одна за другой) с помощью "!"_  

- **git config --global alias.commitall '!git add .; git commit'** - _создание алиаса для добавления всех изменений в текущей директории в индекс и выполнения коммита(не добавляет удаленные файлы)_  

- **git config --global alias.commitall '!git add -A; git commit'** - _создание алиаса для добавления всех изменений в рабочем каталоге(новые, измененные и удаленные файлы)_

---    

- **git config -h** - _опции команды config с описанием_

- **git help config** - _подробная информация о_ **git config**

> **less** - программа для построчного просмотра текста:  
> **/** - поиск по строке или регулярному выражению   
> **n** - поиск вперед  
> **<kbd>SHIFT</kbd> + n** - поиск назад  
> **q** - выход

---    

- **git status** - _текущее состояние рабочего каталога и индекса(отслеживаемые и неотслеживаемые файлы; изменение в индексе; состояние ветки)_

- **git add `<file>`** - _добавление файла в индекс(после чего он станет отслеживаемый)_  

> ![Жизненный цикл состояний файлов](lifecycle.png)

- **git add .** - _добавление всех измененных файлов в текущем каталоге и подкаталогах_

- **git add -A** - _добавление всех файлов, включая неотслеживаемые_

- **git commit** - _запись файла в репозиторий_

- **git commit -m 'Add a welcoming script'** - _коммит с сообщением без вызова редактора_

> git вместе с commit сохраняет информацию о пользователе  

---    

> ___Пример коммита___:
> ```
> [master 463dc4f] Story 182: fix benchmarks for speed
> 2 files changed, 2 insertions(+)
> create mode 100644 README
> ```  
> **master** - ветка, в которой выполнен коммит  
> **463dc4f** - хеш коммита  
> **100644** - 100 тип объекта, который мы сохраняем в git; 644 - права на этот файл(в Windows по умолчанию 644, неисполнимый)

- **git update-index --chmod=+x `<file>`** - _сделать файл исполняемым(например, для Unix-систем), который уже есть в индексе_

- **git add --chmod=+x `<file>`** - _сделать файл исполняемым(например, для Unix-систем), добавив его в индекс_

---    

- **git show** - _показать текущий коммит_


- **git show e740** - _показать текущий коммит по идентификатору(e740 - пример в данном случае) либо его началу(не менее четырёх символов)_


- **git show --pretty=fuller** - _более подробная информация про текущий коммит_

- **git commit --author='John Smith `<address@example.com>`' --date='...'** - _указать автора при коммите_     

---    

- **git reset HEAD `<file>`** - _удаление файла из индекса, оставляя файлы в рабочей директории неизменными_

- **git add --force `<file>`** / **git add -f `<file>`** - _добавление файла в индекс, даже, если они игнорируются в .gitignore_

---    

- **git add -p `<file>`** - _выбрать изменения в файле, которые необходимо добавить в индекс перед коммитом(добавление только определенных изменений)_

---    

- **git commit --all** / **git commit --am 'Your message'** - _коммит всех изменений в остлеживаемых файлах(автоматическое добавление; не включает новые неотслеживаемые файлы; коммит изменений)_  

- **git commit `<path>` -m 'Your message'** - _коммит для одного файла(можно указать несколько путей через пробел); удобно, когда в проекте есть изменения, но мы хотим закоммитить один или несколько файлов, остальные будут нетронуты_  

- **git commit dir/ -m 'Your message'** - _коммит для всех файлов в определённой директории_  

---  

> ___Лучше делать глобальный игнорируемый файл___  

- **git config --global core.excludesFile ~/.gitignore** - _настройка git для использования файла .gitignore для определения файлов и каталогов, которые git должен игнорировать_  

- **git rm -r dir** - _удаление файлов, каталогов из рабочей директории и добавление этого изменения в индекс_  

- **git rm -r --cached src** - _удаление файлов, каталогов из индекса, оставляя их в рабочем каталоге_  

- **git rm -f `<file>`** - _удаление файла из рабочей директории и индекса git, игнорируя предупреждения о несохраненных изменениях_  

---  

- **git mv `<file1>` `<file2>`** - _одновременная команда для переименования и добавления в индекс_
